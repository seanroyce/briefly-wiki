# Phases

Briefly is built in four phases, each grouping related features into a deliverable milestone.

| Phase | Name | Status | Summary |
|-------|------|--------|---------|
| [[Phase 0 - Foundation]] | Foundation | Complete | Repo, Supabase, dev tooling, and Vercel pipeline. |
| [[Phase 1 - MVP]] | MVP | Complete | Full auth, dashboard, 6-step wizard, AI pipeline, gap analysis, brief view, and account settings. |
| [[Phase 2 - Enhanced]] | Enhanced | Planned | Shareable links, templates, version history, duplication, and dark mode. |
| [[Phase 3 - Scale]] | Scale | Planned | Team collaboration, third-party integrations, public API, campaign tracking, and Slack/webhook automation. |
