# 1.4 — Brief Data Layer

Database schema and server actions for all brief CRUD. Tables: `briefs`, `brief_sections`, `uploaded_files`, `gaps` — each with RLS, indexes, and `updated_at` triggers. Zod schemas, TypeScript types. `createBrief`, `updateBrief`, `deleteBrief`, `saveBrief`, `duplicateBrief`, `updateBriefSection`, `bulkUpdateBriefSections`. Data fetchers: `getBrief`, `listBriefs`, `getBriefWithSections`.
