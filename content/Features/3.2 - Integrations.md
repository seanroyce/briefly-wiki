# 3.2 — Integrations

Push completed briefs into the project management and CRM tools teams already use. The headline capability is **brief-to-project-plan export**: an AI step turns a finished brief (timeline, channel strategy, deliverables, dates) into a structured project plan JSON, which is then pushed via tool-specific adapters into Asana, Monday.com, or Jira. CRM links (HubSpot, Salesforce) attach the brief to a campaign or opportunity record. A new `generateProjectPlan` server action plus a `ProjectPlanAdapter` interface keep the AI step decoupled from the destination tool. OAuth connections are managed in account settings and reused per push.

## Remaining

- [ ] AI project plan generation — `generateProjectPlan(briefId)` server action that calls Claude with the full brief and returns structured `{ phases, tasks, owners, dueDates, dependencies }` JSON
- [ ] `ProjectPlanAdapter` interface — common contract: `connect()`, `listWorkspaces()`, `pushPlan(plan, target)`, `getStatus(externalId)`
- [ ] Asana adapter — create project + tasks + sections from generated plan
- [ ] Monday.com adapter — create board + items + groups
- [ ] Jira adapter — create epic + stories + subtasks
- [ ] HubSpot + Salesforce CRM adapters — attach brief metadata to Campaign / Opportunity
- [ ] OAuth connection management — per-tool OAuth flow in `/settings/integrations`, encrypted token storage, disconnect UI
- [ ] Push UI on brief view page — "Send to project tool" button, destination picker, plan preview/edit, push status + external link back
- [ ] Webhook fallback — fire `brief.completed` webhook for tools without a native adapter (see [[Features/3.5 - Slack & Workflow Integration]])
