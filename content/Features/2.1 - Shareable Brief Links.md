# 2.1 — Shareable Brief Links

Generate a unique `share_token` per brief. Public read-only view at `/brief/share/:token` — no auth required. Share/unshare toggle on brief view page. `shareBrief` and `unshareBrief` server actions. `GET /api/shared/:token` route with open RLS policy.
