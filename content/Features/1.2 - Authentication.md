# 1.2 — Authentication

Email/password + Google OAuth via Supabase Auth. Login, signup, forgot/reset password pages. Auth callback route, session middleware (protects `/dashboard`, `/brief/*`, `/settings`), user dropdown in Navbar.

## Remaining

- [x] `users` public profile table migration (id, email, name, avatar_url, auth_provider, created_at) — `003_users_profile.sql`
- [x] DB trigger to auto-create profile row on `auth.users` insert — `on_auth_user_created`
- [x] `updateProfile` dual-writes to `public.users`; `getUser()` reads from `public.users` with auth metadata fallback
- [ ] Edge cases: duplicate email error, OAuth account linking, expired session redirect with preserved URL
