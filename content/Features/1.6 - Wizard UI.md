# 1.6 — Wizard UI

6-step guided wizard at `/brief/new?briefId={id}`. `<WizardStepper>` (pending / active / complete / skipped states). Step content: Import & Overview, Audience & Messaging, Channel Strategy, Budget & Timeline, Metrics & Approvals, Review. `<BriefSectionCard>` with `<SubsectionPreviewTable>`. `<FileUploadZone>` (drag-and-drop, pdf-parse, mammoth, Tesseract.js). `<AIProcessingIndicator>`. Auto-save (3s debounce + on step transition). Brief naming inline. `handleProcessNotes` → `processAllNotes`. `handleProcessContext` → per-section Claude call.
