# 2.3 — Brief Duplication

"Duplicate" action in `<BriefCard>` options menu and brief view header. `duplicateBrief` server action clones the brief + all sections (preserving `structured_content`, `prompt_answers`), appends "(Copy)" to the name, resets status to `draft`.
